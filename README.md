# VR Car Showroom Walkthrough

## Overview
A Unity-based virtual car showroom that allows users to explore vehicles in a 3D environment. Users can navigate through the showroom, inspect cars, customize car colors, and listen to audio-based vehicle information.

## Features
- First-person showroom navigation
- Mouse-controlled camera view
- Car color customization
- Audio narration triggers
- Interactive showroom experience

## Technologies Used
- Unity 3D
- C#
- Visual Studio

## Project Structure
- CarColorChanger.cs
- PlayerMovement.cs
- MouseLook.cs
- NarrationTrigger.cs
- SimpleAudioTrigger.cs

## Future Enhancements
- VR headset support
- Multiple car models
- Vehicle specification panels
- Interactive doors and interiors
